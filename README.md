# MuMu Clean Patch

**当前版本 v1.0.2：恢复第一版“停用应用中心”的去广告方案。**

适配 **Windows MuMu 6.8.8.0 / 安卓 15**。只包含可查看源码的脚本、说明及恢复入口，不包含 MuMu 程序、安卓镜像、个人应用数据或账号信息。

下载：[补丁包 v1.0.2](https://github.com/io-aoleo/mumu-clean-patch/raw/refs/heads/main/downloads/mumu-clean-patch-v1.0.2-MuMu-6.8.8.0.zip) · [SHA256](downloads/mumu-clean-patch-v1.0.2-MuMu-6.8.8.0.zip.sha256)

## 使用前必须了解

**本方案会停用 MuMu 应用中心 com.mumu.store。屏蔽依赖它加载的推广，同时也会失去其商店搜索、下载及相关安装联动功能。**

- 请改用安卓浏览器下载 APK 后通过安卓系统安装器安装，或自行导入 APK。
- 部分 MuMu 拖拽、一键导入或文件关联安装流程也可能依赖应用中心；这些流程未完成全面验证。遇到无法导入时，可使用 MuMu 自带的 ADB 安装 APK，示例见下方。
- 不拦截浏览器网络，不停用安卓系统下载管理器和安装器。浏览器或视频 App 自身的广告不在处理范围内。
- 不保证清除每一个推荐界面。已加载到内存的推广可能需要完全退出并重开 MuMu 才消失。

## 使用

1. 安装 MuMu **6.8.8.0**，启动安卓实例，结束正在进行的更新。
2. 完整解压补丁包，双击 Apply.cmd。若提示权限不足，再右键以管理员身份运行。
3. 完全退出并重新打开 MuMu；双击 Check.cmd 查看状态。

脚本自动从注册表查找唯一安装位置。多份安装或识别失败时，在 PowerShell 指定安装目录：

```powershell
.\Patch.ps1 -Mode Apply -InstallPath 'E:\MuMuPlayer'
```

自定义电脑端广告缓存位置可使用 -DataPath。-SkipAndroid 只处理电脑端，不停用应用中心。

Android 实例必须启动，脚本才能应用其中的设置；以后启动其他实例时需要再次运行。停用应用中心前会检查是否存在独立的默认桌面，无法确认时跳过，避免失去桌面。

## 修改内容

| 项目 | 操作 | 影响 |
| --- | --- | --- |
| 开屏广告缓存 startupImage | 原目录备份，原路径放只读空文件 | 阻止该缓存目录重新生成 |
| 电脑端推广缓存 ProgramAds | 同上 | 阻止该缓存目录重新生成 |
| nx_main/MuMuNxUpdater.exe | 原程序备份，原路径放只读空文件 | 自动及手动更新均受影响 |
| 安卓应用中心 com.mumu.store | 对当前安卓用户停用，保留应用数据 | 商店及部分下载安装联动不可用 |

补丁不会安装或切换桌面，不修改屏幕方向、分辨率、Windows 电源设置，也不启用 root。本机已恢复原 MuMu 定制桌面及自动旋转；Fossify 桌面方案不再作为当前推荐，详见[桌面方案回退说明](docs/desktop-ads.md)。

电脑端显示 blocked=True 表示该路径已阻断；Android 输出 disabled-user，且停用列表出现 package:com.mumu.store 表示应用中心已停用。

## 使用 ADB 自行导入 APK

以下是安装目录为 E:\MuMuPlayer、实例 0 的端口为 16384 时的 PowerShell 示例；安装前自行确认 APK 来源及内容：

```powershell
& 'E:\MuMuPlayer\nx_main\adb.exe' connect 127.0.0.1:16384
& 'E:\MuMuPlayer\nx_main\adb.exe' -s 127.0.0.1:16384 install 'D:\Downloads\your-app.apk'
```

路径换成自己的 APK；端口可通过 mumu-cli.exe info --vmindex 0 查看。ADB 安装不通过 MuMu 应用中心。脚本不会替你下载或安装其他 App。

## 恢复

退出 MuMu 后运行 Restore.cmd，恢复电脑端广告缓存目录和原更新程序。启动安卓实例后再运行一次 Restore.cmd，恢复应用中心默认启用状态；推荐内容也可能随之返回。

原文件保留在同级 .mumu-clean-backup 路径，也兼容 .disabled-20261028 备份。不要删除这些备份。恢复时只移除经过检查的空占位文件，不覆盖非空文件。
